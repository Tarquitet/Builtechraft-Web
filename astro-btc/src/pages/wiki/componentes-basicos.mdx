## WikiTable

Tablas con colores automáticos. Los strings que empiezan por `✓`/`✗` se colorean solos.

<WikiTable
  headers={['Criterio', 'Estado']}
  rows={[
    ['Automático', '✓ good'],
    ['Automático', '✗ bad'],
    ['Manual', { text: 'warn', tone: 'warn' }],
  ]}
/>

```mdx
<WikiTable
  headers={['Criterio', 'Estado']}
  rows={[
    ['Automático', '✓ good'],
    ['Manual', { text: 'warn', tone: 'warn' }],
  ]}
/>
```

Tonos manuales: `good` `warn` `bad` `accent` `muted` `main`.

## WikiCallout

Notas destacadas. Tipos: `info` `warn` `ok` `danger`.

<WikiCallout type="info" title="Ejemplo info">

Texto de información.

</WikiCallout>

```mdx
<WikiCallout type="info" title="Título">

Contenido en **markdown**.

</WikiCallout>
```

## WikiAccordion

Desplegables para no saturar la página.

<WikiAccordion title="Ejemplo desplegable" icon="📂">

Contenido oculto hasta el click.

</WikiAccordion>

```mdx
<WikiAccordion title="Título" icon="📂">

Contenido markdown.

</WikiAccordion>
```
