## Frontmatter (plantilla)

```mdx
---
layout: '@/layouts/WikiLayout.astro'
title: 'Título del artículo'
description: 'Una línea que resume el artículo.'
author: 'Tu nombre'
pubDate: '2026-08-13'
category: 'gameplay'
icon: '📄'
color: 'text-btc-orange'
border: 'hover:border-btc-orange'
order: 10
---
```

## Las 3 reglas de oro

<WikiCallout type="warn" title="Rompen el build si las olvidas">

1. **Línea en blanco** antes y después de cada componente.

2. **Nunca llaves sueltas**: los símbolos {'{'} y {'}'} son JavaScript en MDX.

3. **Links por componente**: usa {'<WikiLink to="faq">'} para wiki, usa {'<a href={links.pages.rules}>'} para páginas principales.

</WikiCallout>

## Regla 1: Líneas en blanco

❌ **MAL:**

```mdx
<WikiCallout type="info">Texto sin línea en blanco.</WikiCallout>
```

✅ **BIEN:**

```mdx
<WikiCallout type="info">

Texto con línea en blanco antes y después.

</WikiCallout>
```

## Regla 2: Llaves son JavaScript

❌ **MAL:**

```mdx
Usa {nombre} para referirte a algo.
```

✅ **BIEN:**

```mdx
Usa {'{'}nombre{'}'} para referirte a algo.
```

## Regla 3: Links por componente

❌ **MAL (wiki):**

```mdx
Lee <a href="/wiki/faq">las preguntas</a>.
```

✅ **BIEN (wiki):**

```mdx
import WikiLink from '@/components/wiki/WikiLink.astro';

Lee <WikiLink to="faq">las preguntas</WikiLink>.
```

✅ **BIEN (página principal):**

```mdx
import links from '@/data/links.json';

Lee <a href={links.pages.rules}>las reglas</a>.
```
