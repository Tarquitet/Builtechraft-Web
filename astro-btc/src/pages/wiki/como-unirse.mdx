Elige la edición de Minecraft que utilizas. Consulta siempre la IP y el puerto actuales en los canales oficiales.

<WikiCallout type="warn" title="IP y puerto pueden cambiar">

Por motivos de seguridad o actualizaciones técnicas, la IP y el puerto del servidor pueden cambiar. Siempre copia los datos actualizados desde nuestro Discord o sitio web.

</WikiCallout>

## Guía de conexión

<WikiTabs>

<WikiTab label="Java Edition">

### 1. Usa la versión correcta

<WikiCallout type="warn" title="Versión mínima: 1.18+">

A partir de esta versión se introdujo el nuevo sistema de generación de terreno. Entrar con versiones más antiguas causará graves problemas visuales o de sincronización.

**Regla de oro:** juega siempre en la última versión estable soportada por el servidor (verifica en Discord).

</WikiCallout>

### 2. Añade el servidor

<WikiSteps
  steps={[
    { title: 'Abre Minecraft Java Edition', text: 'Haz clic en Multijugador.' },
    { title: 'Selecciona Añadir servidor', text: 'Botón en la parte inferior.' },
    { title: 'Nombre del servidor', text: 'Pon "Builtechraft" (o como prefieras).' },
    { title: 'Dirección del servidor', text: 'Pega la IP oficial (cópiala desde Discord o la web).' },
  ]}
/>

### 3. Activa los paquetes de recursos

<WikiCallout type="warn" title="Paso obligatorio">

Antes de guardar el servidor, busca el botón **Paquetes de recursos del servidor** debajo del campo de la IP.

**Debe estar en "Sí"** (o "Enabled"). Nunca lo dejes en "No preguntar" o "Deshabilitado".

**¿Por qué?** Builtechraft utiliza texturas personalizadas inyectadas desde el servidor. Si no aceptas el paquete, verás bloques con texturas extrañas o errores visuales.

</WikiCallout>

### 4. Entra al servidor

<WikiSteps
  steps={[
    { title: 'Haz clic en Hecho', text: 'Para guardar el servidor.' },
    { title: 'Selecciona Builtechraft', text: 'En tu lista de servidores.' },
    { title: 'Haz doble clic', text: 'Para entrar al mundo.' },
  ]}
/>

<WikiCallout type="info" title="No te preocupes si no puedes moverte">

Aparecerás congelado al entrar. Esto es normal: es el sistema de contraseñas del servidor. Lee <WikiLink to="whitelist">Whitelist y registro</WikiLink> para completar el proceso.

</WikiCallout>

</WikiTab>

<WikiTab label="Bedrock (descontinuado)">

<WikiCallout type="danger" title="Soporte descontinuado">

Builtechcraft ya no admite conexiones desde Minecraft Bedrock (móvil, consola, Windows). Esta información se mantiene solo con fines informativos.

Consulta la guía de <WikiLink to="como-unirse">Java Edition</WikiLink>.

</WikiCallout>

</WikiTab>

</WikiTabs>

## Requisitos previos

Antes de intentar conectarte, asegúrate de:

1. **Tener un launcher instalado** - Lee <WikiLink to="launchers">Launchers e instalación</WikiLink>
2. **Estar en la whitelist** - Lee <WikiLink to="whitelist">Whitelist y registro</WikiLink>
3. **Tener la versión correcta** - Verifica en Discord cuál es la versión nativa actual

<WikiCallout type="ok" title="¿Todo listo?">

Si ya tienes launcher, whitelist y versión correcta, ¡conéctate y empieza a construir!

</WikiCallout>
