## La regla de oro

Todos los links viven en `links.json`. En el MDX los usas importando el objeto:

```mdx
import links from '@/data/links.json';

Lee <a href={links.wiki.wikiComparativa}>la comparativa</a>.
```

## Anchors (ir a una sección)

Para linkar a un encabezado concreto, agrega `#slug` al final. El slug es el título en minúsculas y con guiones:

```mdx
<a href={`${links.wiki.wikiComparativa}#fundamentos`}>Ir a Fundamentos</a>
```

<WikiCallout type="warn" title="Markdown [texto](url)">

La sintaxis `[texto](url)` solo acepta URLs literales. Para links de `links.json` usa siempre `<a href={...}>`.

</WikiCallout>
