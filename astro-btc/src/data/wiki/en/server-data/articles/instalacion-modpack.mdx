## Configure technical tools

After installing the modpack, review the settings for these key tools:

<WikiAccordion title="🔧 Litematica">

Use it to **view build schematics**.

**Disable** all placement and automatic interaction features. Use it as a visual reference only.

</WikiAccordion>

<WikiAccordion title="📊 MiniHUD">

It displays technical information about the world (coordinates, biome, TPS, and more).

**Do not enable** options that reveal hidden world data, such as structures or spawners.

</WikiAccordion>

<WikiAccordion title="🗺️ VoxelMap">

It stores maps and local waypoints.

**Do not import or share** private locations without the owner's permission. Respect other players' work.

</WikiAccordion>

<WikiAccordion title="🌐 Bobby">

It keeps chunks already received by your client, extending the view beyond what the server currently sends.

**Important:** Bobby does not fetch new chunks or show remote changes until you approach the area. If a build has changed, you must visit it for your client to refresh it.

</WikiAccordion>

## Install the optional cache

The Bobby and VoxelMap caches reduce visual loading time in areas already visited by other players. They may use **more than 1 GB** of disk space.

<WikiCallout type="warn" title="The cache may show old builds">

If someone changed an area after its cache was created, **you will keep seeing the old version** until you visit it. Never make decisions based only on cached views.

</WikiCallout>

## Pre-join checklist

Before connecting to the server, check that:

<WikiCallout type="ok" title="Final checklist">

- ✅ You are using the server's current native version.
- ✅ You only have **approved client mods** (see <WikiLink to="lista-mods">the mod list</WikiLink>).
- ✅ Macros, automation, and advantage-granting tools are **disabled**.
- ✅ Automatic Litematica, MiniHUD, and similar features are **disabled**.

</WikiCallout>

<WikiCallout type="danger" title="If you cannot identify a file">

**Do not load it.** Ask staff for confirmation through the Discord forum before using it.

</WikiCallout>
