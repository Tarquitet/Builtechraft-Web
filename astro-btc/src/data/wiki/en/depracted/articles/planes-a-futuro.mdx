Builtechraft has a **public roadmap** where we track improvements, features, and projects in progress or under consideration.

## What is the roadmap?

The roadmap is an updated list of:

- **Features in development:** what we are building now.
- **Planned improvements:** what we hope to add next.
- **Future ideas:** concepts we are evaluating.
- **Completed projects:** what has already launched.

<WikiCallout type="info" title="Our roadmap philosophy">

We do not promise exact dates. We take the time needed to keep the experience stable and balanced. If an idea is not ready, it does not ship.

</WikiCallout>

## Where to find the roadmap

The official roadmap is on the main page, in the **About → Future Plans** section.

<WikiCallout type="tip">

Visit the <a href="/#roadmap">roadmap section</a> to see the current status of each project.

</WikiCallout>

## How the roadmap is organized

Projects are grouped by the kind of improvement:

<WikiAccordion title="Technical improvements">

Performance optimization, bug fixes, command improvements, and server systems.

**Examples:**

- Carpet scripts for sitting and riding (replacing the current system).
- Migrating systems to custom datapacks.
- Authentication improvements.

</WikiAccordion>

<WikiAccordion title="New features">

New features that expand what you can do on the server.

**Examples:**

- An internal achievement system.
- Private group waypoints.
- Web map improvements (filters and history).

</WikiAccordion>

<WikiAccordion title="Events and community">

Activities organized for the player community.

**Examples:**

- Building competitions.
- Technical farm fairs.
- Guided tours of notable builds.

</WikiAccordion>

## How to follow progress

<WikiAccordion title="On the website">

The roadmap section at `/#roadmap` displays each project's status with color badges:

- **🟢 Complete:** available on the server.
- **🟡 In progress:** actively being developed.
- **🔵 Planned:** expected to be implemented soon.
- **⚪ Idea:** under consideration.

</WikiAccordion>

<WikiAccordion title="On Discord">

Important updates are posted in the Discord announcements channel, including:

- New feature releases.
- Changes to project status.
- Requests for community feedback.

</WikiAccordion>

<WikiAccordion title="In this wiki">

When a roadmap feature launches, we document how to use it here. For example:

- A new command gets a usage guide.
- A new mechanic gets an explanation.
- A system change updates the affected articles.

</WikiAccordion>

## Can I suggest an idea?

<WikiCallout type="ok" title="Yes, we would love to hear it">

Share your proposal in the suggestions channel on our <WikiLink to="discord">Discord</WikiLink>.

Community ideas often make it onto the roadmap. Public waypoints and decorative heads both started as player suggestions.

</WikiCallout>
