## The golden rule

Keep reusable external and main-page URLs in `links.json`, then import the object in MDX:

```mdx
import links from '@/data/links.json';

Read <a href={links.wiki.wikiComparativa}>the comparison</a>.
```

For links between wiki articles, use the `WikiLink` component with the article slug:

```mdx
import WikiLink from '@/components/wiki/WikiLink.astro';

Read <WikiLink to="faq">the frequently asked questions</WikiLink>.
```

## Anchors (link to a section)

Append `#slug` to the URL to link to a heading. The slug uses lowercase words separated by hyphens:

```mdx
<a href={`${links.wiki.wikiComparativa}#fundamentos`}>Go to Fundamentals</a>
```

<WikiCallout type="warn" title="Markdown [text](url)">

The `[text](url)` syntax only accepts literal URLs. For values from `links.json`, use `<a href={...}>`.

</WikiCallout>
