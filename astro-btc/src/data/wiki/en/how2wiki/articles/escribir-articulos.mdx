## Frontmatter template

```mdx
---
layout: '@/layouts/WikiLayout.astro'
title: 'Article title'
description: 'A one-line summary of the article.'
author: 'Your name'
pubDate: '2026-08-13'
category: 'features'
icon: '📄'
color: 'text-btc-orange'
border: 'hover:border-btc-orange'
order: 10
---
```

## Three golden rules

<WikiCallout type="warn" title="These can break the build">

1. **Leave a blank line** before and after every component.
2. **Never use bare braces:** `{` and `}` are JavaScript syntax in MDX.
3. **Use the right link component:** use `WikiLink` for wiki articles and links from `links.json` for main pages.

</WikiCallout>

## Rule 1: Blank lines

❌ **Incorrect:**

```mdx
<WikiCallout type="info">Text without a blank line.</WikiCallout>
```

✅ **Correct:**

```mdx
<WikiCallout type="info">

Text with a blank line before and after.

</WikiCallout>
```

## Rule 2: Braces are JavaScript

❌ **Incorrect:**

```mdx
Use {name} to refer to something.
```

✅ **Correct:**

```mdx
Use {'{'}name{'}'} to refer to something.
```

## Rule 3: Use link components

❌ **Incorrect (wiki):**

```mdx
Read <a href="/wiki/faq">the questions</a>.
```

✅ **Correct (wiki):**

```mdx
import WikiLink from '@/components/wiki/WikiLink.astro';

Read <WikiLink to="faq">the questions</WikiLink>.
```

✅ **Correct (main page):**

```mdx
import links from '@/data/links.json';

Read <a href={links.pages.rules}>the rules</a>.
```
