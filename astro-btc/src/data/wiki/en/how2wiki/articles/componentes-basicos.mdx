## WikiTable

Tables with automatic colors. Strings that start with `✓` or `✗` are colored automatically.

<WikiTable
  headers={['Criterion', 'Status']}
  rows={[
    ['Automatic', '✓ good'],
    ['Automatic', '✗ bad'],
    ['Manual', { text: 'warn', tone: 'warn' }],
  ]}
/>

```mdx
<WikiTable
  headers={['Criterion', 'Status']}
  rows={[
    ['Automatic', '✓ good'],
    ['Manual', { text: 'warn', tone: 'warn' }],
  ]}
/>
```

Manual tones: `good`, `warn`, `bad`, `accent`, `muted`, `main`.

## WikiCallout

Highlighted notes. Types: `info`, `warn`, `ok`, and `danger`.

<WikiCallout type="info" title="Info example">

Informational text.

</WikiCallout>

```mdx
<WikiCallout type="info" title="Title">

**Markdown** content.

</WikiCallout>
```

## WikiAccordion

Expandable sections that keep a page concise.

<WikiAccordion title="Expandable example" icon="📂">

Content hidden until clicked.

</WikiAccordion>

```mdx
<WikiAccordion title="Title" icon="📂">

Markdown content.

</WikiAccordion>
```
