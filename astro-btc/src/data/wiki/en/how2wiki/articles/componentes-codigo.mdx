## WikiCommand

A command block with a copy button.

<WikiCommand command="/tpa <player>" description="Copy the command with one click." />

```mdx
<WikiCommand command="/command" description="What it does." />
```

## WikiKbd

Inline keys styled like keycaps.

Press <WikiKbd>Ctrl</WikiKbd> + <WikiKbd>C</WikiKbd> to copy.

```mdx
<WikiKbd>Ctrl</WikiKbd> + <WikiKbd>C</WikiKbd>
```

## WikiBadge

Inline status pills.

Difficulty <WikiBadge tone="good">Easy</WikiBadge> · Version <WikiBadge tone="info">1.21</WikiBadge> · Status <WikiBadge tone="warn">Beta</WikiBadge>

```mdx
<WikiBadge tone="good">Easy</WikiBadge>
```

Tones: `good`, `warn`, `bad`, `accent`, `info`, and `muted`.
